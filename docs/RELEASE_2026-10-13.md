# HALLAYM EDU — 2026-10-13 resurs va videodars yangilanishi

## O'zgarishlar
- Kurs videolari ketma-ket: oldingi mavzu tugallanmagan bo'lsa keyingi mavzu API va UI darajasida yopiq.
- Video progressi oxirgi soniyadan davom etadi; tugallanish uchun tomosha qilingan vaqt va yakuniy pozitsiya birga hisoblanadi.
- Fan → mavzular → resurs tahriri oynasidan qaytishda shu fan va ochilgan mavzu saqlanadi.
- O'qituvchining shaxsiy resurslari: GridFS-da bitta nusxa, kurslarga ACL bilan ko'p marta ulash.
- Bir martada 1–30 ta fan/guruhga biriktirish; shaxsiy saqlash rejimi.
- PDF/PPT/DOC/XLS/rasmlar, audio, video va ZIP; 30MB ZIP, 35 fayl, 90MB ochilgan umumiy hajm.
- ZIP fayl nomi: `01__Mavzu sarlavhasi__Material sarlavhasi.pdf`. Mavzu sarlavhasi fanda mavjud bo'lsa avtomatik bog'lanadi.
- Video GridFS-ga 1GB gacha streaming: `my-assets/video-upload`; HTML5 player byte ranges orqali ko'radi.
- Videoni ixtiyoriy HTTPS URL yoki shaxsiy fayldan qo'yish; JPG/PNG/WebP muqova shaxsiy fayldan.
- Topshiriqlarni ko'p fanlarga yaratish; elektron kutubxonada carlib.kstu.uz HTTPS iframe + yangi oynada ochish.
- Tashkilot logosini va PWA PNG icon'ni qurilmadan yuklash.
- Talaba kamerasini qo'l bilan ON/OFF; lokal proktor trek saqlanadi. Samsung kabi kameralar uchun yengil constraints va native→MediaPipe fallback.
- Telegram ixcham interfeysli resurs oynasi va mobil layout.

## Deploydan avval
- Ma'lumotlar bazasi zaxirasini oling; ishlayotgan darslarni to'xtatmay deploy qilmang.
- serverda `git status --short`: no-commit local changes yo'q bo'lishi shart.
- Node >=22, npm, MongoDB GridFS, nginx media upload sozlamalari mavjud bo'lishi kerak.
- `npm ci --no-audit --no-fund`
- `npm --prefix media-server ci --no-audit --no-fund`
- `npm run build:media-client && npm run check && npm test`
- `sudo systemctl restart masofaviy2 masofaviy2-media`
- `sudo systemctl status masofaviy2 masofaviy2-media --no-pager`
- `curl -fsS https://hallaym.kstu.uz/api/health`

## QA checklist
1. Talaba: 1-mavzu yarim ko'rilgan — 2-mavzudagi tugma o'chgan; endpoint ruxsat bermaydi.
2. 1-mavzuni yakunlash — 2-mavzu qayta yuklanganda ochiladi.
3. O'qituvchi: bitta faylni shaxsiy saqlaydi, keyin 2 guruhga biriktiradi; link o'chsa original fayl qoladi.
4. `01__1-mavzu__Maruza.pdf` ZIP ichida mavzuga bog'lanadi.
5. 80 daqiqalik MP4 yuklanadi (tarmoq va storage hajmini nazorat qiling); bir xil videoni 2 fanga joylashtiring.
6. Qurilmadan muqova tanlash, talaba ko'rishi, PNG PWA icon va logoni yuklash.
7. Fan ichidan modal tahrir va Orqaga — ochilgan mavzuga qaytadi.
8. Redmi 10A, Samsung Galaxy S26: proktor kamera, xatolardan so'ng fallback, dars kamerasi ON/OFF.
9. iPhone/Android mobil: Telegram UI, video fullscreen, gorizontal aylanish, fon va PiP.
10. carlib iframe bloklansa 'Alohida ochish' havolasini ishlating.
